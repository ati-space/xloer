# Xloer: kurulum dosyaları

Xloer, Windows için görev ve rapor takip uygulamasıdır (TickTick tarzı listeler,
sürükle-bırak, aramalı masaüstü widget'ı). Bu depoda yalnızca kurulum dosyaları
ve güncelleme bilgisi bulunur; uygulama yüklü Xloer'e yeni sürümleri buradan sorar.

**İndir:** [Son sürüm](https://github.com/ati-space/xloer-releases/releases/latest)

- `Xloer-Setup-x.y.z.exe`: kurulum sihirbazı; kendini otomatik günceller
- `Xloer-Portable-x.y.z.exe`: kurulumsuz tek dosya; yeni sürüm çıkınca haber verir

Uygulama imzasız olduğu için Windows ilk açılışta uyarı gösterebilir:
**Ek bilgi → Yine de çalıştır**.
